# Algorithm Lab

Java lab for algorithm experiments, small problem solutions, and implementation notes.

## Purpose

This repository is a sandbox for practicing algorithms and comparing implementation approaches. It is intentionally lightweight and optimized for learning speed.

## Contents

- Java source files for algorithm exercises.
- Small experiments that can be promoted into cleaner kata-style examples later.

## How To Use

Open the project in IntelliJ IDEA and run individual classes or tests from the IDE.

## Status

Active learning lab. The main gap is structure: problems should eventually be grouped by domain such as arrays, graphs, dynamic programming, concurrency, and search.

## Validation

Promote experiments into repeatable examples by adding sample inputs, expected outputs, and complexity notes.

## Engineering Notes

Keep exploratory code separate from polished kata implementations so the repo stays useful both for learning and review.
